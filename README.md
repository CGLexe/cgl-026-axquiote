# Axquiote Cocina de Origen — Oaxaca

Landing one-page de **CGL Design** (restaurante).

> **Deploy directo del export de Google Stitch**
> (`stitch_minimalist_restaurant_website.zip`). Los datos salieron del
> export, no del dueño.

## Qué hay aquí

| Archivo | Qué es |
|---|---|
| `index.html` | La página (`axquiote_cocina_de_origen_oaxaca/code.html`). Secciones `#propuesta` `#menu` `#galeria` `#visitanos`. |
| `DESIGN.md` | El sistema de diseño (`tierra_humo`). |
| `vercel.json` | Config mínima para estático en Vercel. |

## Navegación

El export traía todo el nav muerto (`href="#"`). Snippet `CGL-NAV`
antes de `</body>`: `home→#top`, `filosofia→#propuesta`,
`propuesta-y-chefs→#propuesta`, `menu→#menu`, `galeria→#galeria`,
`visitanos→#visitanos`, `reservaciones→#visitanos` (no tiene sección
propia; contacto y horarios están en `#visitanos`). Se agregó
`id="top"` al `body`. Externos intactos (Instagram, Maps, `tel:`).
